# 待开发需求池

**创建日期**: 2026-05-08  
**来源依据**: 根目录 `需求规格说明书.md`、`docs/FUNCTION_DOCUMENTATION.md` 与 `docs/CURRENT_IMPLEMENTATION_STATUS.md` 的差距对照。  
**文档定位**: 本文档用于沉淀“总需求已提出，但当前实现尚未完全匹配”的待开发事项。总需求池继续由需求文档维护；当前实现状态由 `docs/CURRENT_IMPLEMENTATION_STATUS.md` 维护。

## 1. 需求池规则

| 字段 | 说明 |
| --- | --- |
| 优先级 | P0 为核心闭环缺口，P1 为重要增强，P2 为体验或治理优化，P3 为远期扩展 |
| 匹配状态 | 未实现、部分实现、占位实现、需核验 |
| 来源模块 | 对应总需求中的业务模块 |
| 验收标准 | 后续开发完成后用于判断是否可移出待开发池 |

## 7. 出池标准

待开发项满足以下条件后，可以从本文档移除或移动到历史完成记录：

1. 代码实现已完成，并覆盖前端、后端、合约或数据迁移中涉及的必要部分。
2. 相关接口和页面已按总需求完成验收。
3. 已补充或更新对应需求文档、数据库文档或接口说明。
4. 已通过对应层级验证，例如后端测试、前端构建/检查、合约测试或端到端手工核验。
5. `docs/CURRENT_IMPLEMENTATION_STATUS.md` 已同步更新实现状态。
